# Датский квартал — статус сессии (восстановление)

Проект: 24 вертикальные карточки 2:3 (телефон) с чистыми планировками для ЖК
«Хрустальный парк», квартал «Датский квартал».

## ⚠️ Что произошло с прежним контекстом

Предыдущая сессия работала в эфемерном контейнере на ветке
`claude/fervent-fermat-x3amvp` и **не запушила результаты**. Эта ветка
отсутствует на remote; файлы `SESSION_STATUS.md`, `scripts/clean_jobs.json`,
`scripts/render.py`, `fonts/` не нашлись ни в одной ветке и ни в Google Drive.
Контекст пришлось восстанавливать из истории Higgsfield и Drive.

## Что восстановлено

- **Промпт очистки** планировок (nano_banana_2) — в `scripts/clean_jobs.json`
  (`clean_prompt`). Стиль: тёмные стены-poché с текстурой, площади и пропорции
  сохранены, размеры/оси/уровни/заливка убраны, белый фон.
- **25 уникальных готовых job'ов** очистки (поле `unique_clean_jobs`) с
  `result_url` (CloudFront) и `source_url`. Задача предполагает 24 карточки —
  один из 25 источников, вероятно, лишний дубль/реролл; нужно отсмотреть глазами.
- **Drive-папка** `1OswUx8Mkan7KiF-BL6zstZ0OBCMqmFFS` («Дуплексы все разные
  цвета») — содержит **исходные** планировки (`д.4,14 №3`, `д.11 №5`, …) и
  «Frame 8–13» (тоже исходники с размерами/осями, не готовые карточки).

## Конвейер (готов к запуску)

1. `fonts/` — Playfair Display + Manrope (вариативные TTF, кириллица).
2. `scripts/render.py` — рендер карточки 2:3 (1200×1800), белый фон,
   надзаголовок «ХРУСТАЛЬНЫЙ ПАРК», заголовок «Датский квартал» (Playfair),
   акцент `#52358B`, подпись «Дом №X · Квартира №Y · Z этаж» (Manrope),
   планировка по центру. Протестирован на плейсхолдере.
3. `scripts/download_clean.py` — качает `result_url` → `assets/plans_clean/<src>`.
4. `scripts/clean_jobs.json` — перечень job'ов + заготовка `cards[]`.

## Блокеры (нужен пользователь / новая сессия)

1. **Egress к CloudFront закрыт** в этой сессии (`403 host_not_allowed` на
   `d8j0ntlcm91z4.cloudfront.net` и `d2ol7oe51mr4n9.cloudfront.net`), хотя
   предполагался доступ к `*.cloudfront.net`. Сетевая политика задаётся при
   создании окружения → вероятно, нужна **новая web-сессия** с разрешёнными
   хостами. Без этого скачать планировки нельзя.
2. **Подписи 24 карточек** (`house` / `apartment` / `floor` / `caption`) —
   утеряны и невосстановимы из артефактов (особенно номера этажей). Нужно
   заполнить `cards[]` в `clean_jobs.json` (мэппинг clean_job → дом/квартира/этаж).

## Как до-выпустить (когда egress открыт и подписи есть)

```bash
python3 scripts/download_clean.py     # assets/plans_clean/*.png
python3 scripts/render.py             # outputs/cards/*.png
```
Затем: проверить карточки глазами, прислать PNG пользователю, выгрузить в
Drive-папку `1OswUx8Mkan7KiF-BL6zstZ0OBCMqmFFS`.
